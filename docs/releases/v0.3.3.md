# v0.3.3 release notes

This patch release includes the event details feature merged in [PR #21](https://github.com/griswaldbrooks/boardgame-collector/pull/21).

- **Expandable upcoming-event cards.** Each card in the upcoming-events list on the Events page expands in place to show the full event details from the same credential-free public calendar read — no new network calls, no credentials.
- **Copyable venue addresses.** The expanded card offers the venue address as a copy-ready block for pasting into a maps app, so coordinators can route to a venue without retyping it.
- **Source links.** The expanded card links to the public event page, so the details can be checked at the source.

The Home next-event card, the calendar cache (`bgn.calendar.v1`), and the honest stale/empty states are unchanged. The app still does not send mail, add Google Groups members, or submit Luma events itself.

## Release metadata

- App version: `0.3.3`; Tauri derives Android `versionCode` **3003**, up from **3002** in `0.3.2`.
