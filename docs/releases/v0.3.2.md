# v0.3.2 release notes

This patch release includes the cleanup merged in [PR #18](https://github.com/griswaldbrooks/boardgame-collector/pull/18).

- **Remove unavailable agent shortcuts.** All five nonfunctional agent shortcuts are removed from single signup, batch signup, broadcast, Luma event, and contact screens.
- **Keep the working manual flows.** Signup capture and batch queueing, editable broadcast drafts and mail-app handoff, Luma preview and manual handoff, and local contact saving remain available and unchanged.
- **Safe stale navigation.** An old agent-route request falls back to Home instead of opening an unavailable stub.

There is no Discord integration in this release. The app still does not send mail, add Google Groups members, or submit Luma events itself.

## Release metadata

- App version: `0.3.2`; Tauri derives Android `versionCode` **3002**, up from **3001** in `0.3.1`.
- Updater contract: tag `v0.3.2`, asset `bgn-coordinator_0.3.2_arm64.apk`.
- This PR changes release metadata and notes only; PR #18's product behavior is unchanged. Merging it to `main` triggers the existing signed arm64 APK build and publication workflow, provided the tag is still absent and the workflow succeeds. Preparing this PR does not publish an APK or release.
