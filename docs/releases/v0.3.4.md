# v0.3.4 release notes

- **Take a note.** Home opens a private, on-device scratchpad with multiline notes,
  inline editing and confirmed deletion. Revised notes return to the top. Empty
  saves are refused; local-storage errors retain the draft rather than claim a save.
- **Notes recovery.** Nonempty notes get separate dated snapshots in
  `Downloads/BGN Coordinator/` on changes and launch through the existing Android
  backup bridge. Empty notes offer Home restore, with a session-only Not now.
  Notes also supports explicit add-only file import; stale copies never overwrite
  an existing note. General notes are not shared through Send to Meeple.
- **Shared picker safety.** Contacts, signup recovery and notes cannot replace one
  another's pending document-picker callback.

The candidate also includes the previously merged private Meeple handoff from
PR #20; its native/private-receiver activation and privacy gates remain unchanged.
No receiver or service is deployed by this notes PR.

## Release metadata and gates

- App version: `0.3.4`; Tauri derives Android `versionCode` **3004**.
- Updater contract: tag `v0.3.4`, asset `bgn-coordinator_0.3.4_arm64.apk`.
- Latest published version checked before this bump: `v0.3.3`.
- This branch prepares the version only. **Do not merge/release without owner
  approval**: merging triggers the existing signed arm64 publication workflow if
  the tag is absent. No APK or release was produced by this work.
- Chromium/DOM verification uses synthetic records and a stubbed native backup
  bridge. Android MediaStore writes, document picker, reinstall recovery and soft
  keyboard behavior still require native verification before release.
- Backup limitations remain device-local: API 29+, plaintext Downloads files,
  best-effort writes, and a 1 MiB snapshot/picker ceiling. Deleting a note does not
  erase its historical backups.
