# v0.3.6 — private signup receipt and reconciliation dates

**Prepared, not released. No live Google add proven.** Latest published release
and upstream main were v0.3.5 when this bump was prepared. Recheck both before
owner merge; a merge triggers the signed APK release pipeline (ADR 0006).

- Send to Meeple history separates submission receipt, first record receipt,
  actual addition date, and locally recorded membership verification. Unknown
  dates stay Unknown; manual Refresh outcomes retains last-known dates offline.
- The private receiver keeps immutable captured names/sources and receipts,
  membership outcome history, and private JSON export / consistent SQLite backup.
  This is a reconciliation ledger, not a current Google roster.
- Contacts never become mailing-list additions. Receipt is not membership;
  verification dates are operator-attested, not independent Google checks.

Receiver activation is separate and owner-gated. The transport already shipped
in v0.3.2 supports runtime-approved HTTPS `*.ts.net` origins; this version adds
the date display, not a new endpoint entitlement. No receiver is activated by
merging this PR. No Google adapter, login automation or enrollment cron is added.
Google authentication and actual membership feedback remain blocked/unproven.
