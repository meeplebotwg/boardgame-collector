# v0.3.1 release notes

This patch release includes the fixes merged in [PR #16](https://github.com/griswaldbrooks/boardgame-collector/pull/16).

- **Event-based, editable messages.** Templates use the selected event's known facts from the last-known public calendar instead of sample event details. Unknown details are omitted, and the final draft remains editable. Recaps require an explicit actual attendance count, never an RSVP-derived estimate; switching events clears that count and the recap draft so attendance cannot carry over.
- **Honest mail handoff.** Confirmation, receipt, and activity describe opening a draft in the mail app, not sending or delivering it. A failed handoff leaves the edited draft available to retry without recording a successful handoff.
- **Recoverable pending signups.** Pending signups get best-effort, device-visible snapshots on changes and launch. Recovery is explicit and additive, deduplicates addresses without overwriting current queue metadata or intents, and keeps contact backups separate. Recovery warns that older snapshots may contain already-completed signups. Unique snapshot names avoid overwrites; pruning requires a confirmed write and coverage of every older pending address, so failed writes and empty or reduced queues cannot discard recovery-rich snapshots.

Backups remain plaintext on this device in `Downloads/BGN Coordinator/`, not cloud sync. After reinstall, use the document picker to reach older files. The app still does not send mail or add Google Groups members itself.
